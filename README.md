# IoT-Based Adaptive Traffic Control System

## Project Overview

This project presents an IoT-based adaptive traffic control system designed to manage traffic efficiently at a four-road junction. The system monitors real-time traffic density using sensors and dynamically adjusts traffic signals to reduce congestion and improve flow.

It also includes an emergency vehicle detection feature that gives priority by automatically turning the signal green, ensuring faster and safer movement.

---

## Objectives

* Reduce traffic congestion
* Automate traffic signal control
* Provide priority for emergency vehicles
* Improve road safety and efficiency

---

## Components Used

* Arduino Microcontroller
* Camera Module
* Servo Motor
* IR Sensors / Ultrasonic Sensors
* Power Supply
* Connecting Wires

---

## Key Features

* Real-time traffic density monitoring
* Automatic signal switching
* Emergency vehicle priority system
* 360-degree monitoring using rotating camera
* Low-cost and efficient design

---

## Working Principle

1. Sensors and camera monitor traffic on all four roads.
2. The system analyzes traffic density in real time.
3. Signals are dynamically adjusted based on vehicle count.
4. Roads with higher density receive longer green signals.
5. When an emergency vehicle is detected within a specific range, the system prioritizes that road by turning the signal green.
6. A servo motor rotates the camera to cover all directions.
